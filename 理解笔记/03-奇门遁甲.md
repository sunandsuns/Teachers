# 《奇门遁甲》深度理解笔记

> 逐概念深解其义理、设计意图与哲学内涵。
> 不仅讲"是什么"，更要讲"为什么"——古人为什么这样设计这套符号系统，它在表达什么世界观。

---

## 一、总论：奇门遁甲到底是什么

### 一句话定性

奇门遁甲是中国古人构建的一套**以时间起局、以九宫为空间框架、以天地人神四层符号为变量**的传统决策模型。它不是迷信，也不是科学，而是**一种把"时机—方位—人事—不可控因素"四维信息编码进同一个盘面，用以辅助决策的符号系统**。

### "三式之首"意味着什么

太乙、奇门、六壬合称"三式"，各有所主：

| 式 | 所主 | 用途 |
| --- | --- | --- |
| 太乙 | 天时 | 测国运、大势 |
| 奇门 | 方位/时机 | 择时择方、军事决策 |
| 六壬 | 人事 | 占具体人事得失 |

奇门居首，不是因为"最准"，而是因为它**把天时、地利、人事、神助四层同时编入一局**——维度最全，故称"帝王之学"。**古时帝王决策，面对的从来不是单一变量，而是天时、地利、人和、未知因素的交织**，奇门的设计正是回应这种复杂性。

### 核心原理的深层用意

> "以时间起局，把天、地、人、神四个层面的信息编织进洛书九宫。"

**深解**：这句话是奇门遁甲的"总纲"。它的深意在于——

1. **以时间起局**：不问你心里想什么，只问"此刻是什么时辰"。**把主观意图悬置，先看客观时间结构**——这是一种"先客观后主观"的思考方式，与易经"因时而变"的传统一脉相承。
2. **四层信息编入一局**：天地人神不是玄学概念，而是**四个维度的变量**——天时（环境大势）、地利（空间条件）、人事（行动者）、神助（不可控/未知因素）。这四层对应现代决策的"宏观环境—中观资源—微观行动—不确定性"。
3. **编织进九宫**：九宫是空间框架。**把四层时间变量落到空间方位上，形成"时空—行动"的可视化盘面**——这是古人在没有数据可视化技术时，用符号构建的"决策仪表盘"。

### 两大分类的取舍

- **数理奇门**：以符号推演，本质是**符号逻辑系统**，可学可传。
- **法术奇门**：涉及咒语秘诀，常被视为迷信，本汇编不涉及。

**深解**：奇门分两路，正说明它既被当作"可推演的符号系统"（数理），也被当作"可通灵的神秘术"（法术）。**真正值得现代人研究的是数理奇门**——它是一套成熟的符号推演体系，与现代信息系统有结构上的相似性。

### 起源传说的隐喻

相传黄帝战蚩尤时九天玄女授术，4320 局 → 风后 1080 局 → 姜太公 72 局 → 张良 18 局。

**深解**：这条传承线的数字变化（4320→1080→72→18）本身是一个**"由繁入简"的演化叙事**。它暗示奇门的核心不是"局数多"，而是**"规律简"**——越到后代越精炼，说明后人不断从庞杂的案例中提炼出更普适的规则。18 局（阳遁九局+阴遁九局）是奇门的最终骨架，与一年阴阳两半、九宫方位完全对应。**这种由繁入简的演化路径，本身是一种认知进步的叙事**。

## 二、四盘框架：天地人神的深层设计

| 盘 | 内容 | 象征 | 深解 |
| --- | --- | --- | --- |
| 天盘 | 九星 | 天时（气数、能力、气质） | 环境"是什么气数"——大势与氛围 |
| 地盘 | 三奇六仪 | 地利（干支符号） | 空间"是什么条件"——资源与位置 |
| 人盘 | 八门 | 人事（行为状态/行动通道） | 人"该做什么"——行动选项 |
| 神盘 | 八神 | 无形助力 | 未知"会怎样"——不可控因素 |

**四盘设计的哲学深意**：

古人在没有现代系统论语言时，用"天、地、人、神"四字概括决策的全部变量。这四层不是神秘主义的堆砌，而是一个**完整的决策要素分解**：

- **天盘（天时）**：你改变不了的大环境——时代、节气、大势。**对应现代决策的"宏观环境"**。
- **地盘（地利）**：你所在的具体位置与资源条件。**对应"中观资源"**。
- **人盘（人事）**：你能采取的行动。**对应"微观行动"**。
- **神盘（神助）**：所有你算不到、控制不了的因素。**对应"不确定性/运气"**。

**九星 vs 八门的区别**：

> 九星比喻为事物呈现的**能力与气质**，八门则是**行动通道或事件状态**。

**深解**：九星是"是什么"（环境给定的性质），八门是"该做什么"（可选择的行动）。**星是静态的给定，门是动态的通道**——这区分极重要：星告诉你"此刻气数如何"，门告诉你"此刻往哪条路走"。一静一动，构成"知—行"的闭环。

## 三、九宫洛书：空间框架的数学之美

### 九宫排布（传统"上南下北"）

```
┌───────┬───────┬───────┐
│ 巽四宫 │ 离九宫 │ 坤二宫 │
│ (东南) │ (南)   │ (西南) │
├───────┼───────┼───────┤
│ 震三宫 │ 中五宫 │ 兑七宫 │
│ (东)   │ (中)   │ (西)   │
├───────┼───────┼───────┤
│ 艮八宫 │ 坎一宫 │ 乾六宫 │
│ (东北) │ (北)   │ (西北) │
└───────┴───────┴───────┘
```

### 洛书数字的奥秘

| 宫位 | 八卦 | 方位 | 五行 |
| --- | --- | --- | --- |
| 一宫 | 坎 | 正北 | 水 |
| 二宫 | 坤 | 西南 | 土 |
| 三宫 | 震 | 正东 | 木 |
| 四宫 | 巽 | 东南 | 木 |
| 五宫（中） | — | 中央 | 土（天禽居中，寄二宫） |
| 六宫 | 乾 | 西北 | 金 |
| 七宫 | 兑 | 正西 | 金 |
| 八宫 | 艮 | 东北 | 土 |
| 九宫 | 离 | 正南 | 火 |

**记忆口诀**："戴九履一、左三右七、二四为肩、六八为足"。

**深解·洛书数字的数学美**：洛书九宫的数字排列是一个**三阶幻方**——横、竖、对角线相加都等于 15。这不是巧合，是古人从天文观测（北斗旋转、四季方位）中提炼出的空间数学结构。**奇门把一切变量落到这个幻方上，意味着所有关系都遵循"对称—平衡—守恒"的数学美感**。

**中五宫的特殊性**：中宫是 5，是九宫的几何中心与数字中心。它不直接落星门，而是**天禽星居中、寄附于二宫（坤）**。**这个设计反映古人对"中央"的敬畏——中心不可直接占据，必须"寄"在边上**，与帝王"居中而治"的政治哲学暗合：真正的中心是空的，是枢纽，不是某一方的专属。

### 五行分布的方位逻辑

- 北水、南火、东木、西金、中土——**五行配五方**，是古人观察天象与季节得出的对应：北方寒冷属水，南方炎热属火，东方日出草木生属木，西方日落肃杀属金，中央承载一切属土。
- 八宫五行分布还暗含**相生相克环**：北水生东木，东木生南火，南火生中土，中土生西金，西金生北水——**九宫五行构成一个相生循环，意味着空间本身是有"流转"的**。

## 四、八门：人事行动的八种状态

### 吉凶分类

- **三吉门**：开门、休门、生门
- **凶门**：死门、惊门、伤门
- **中平门**：杜门、景门

**深解·为什么是三吉三凶两平**：八门对应八卦，但吉凶不是八卦本身的属性，而是**根据人事的"宜不宜"来分**——开门是开放（宜进取）、休门是休整（宜守成）、生门是生长（宜谋利）；死惊伤三门分别对应终止、惊扰、损伤，皆不宜主动行动。**吉凶的本质是"行动与时位的契合度"**，不是门本身的善恶。

### 各门象意深解

| 门 | 象意 | 深解 |
| --- | --- | --- |
| 开门 | 开放、事业、机会、通达 | "开"是主动打开——利开拓、求职、公职。**吉在能"通"**。 |
| 休门 | 休养、安定、交流、缓和 | "休"不是停滞，是**主动休整以存势**。吉在"缓"，有时不动比动好。 |
| 生门 | 生长、资源、收益、活力 | "生"是生机勃发——利求财、谋事。**吉在"长"**。 |
| 伤门 | 竞争、行动、损伤、冲突 | "伤"未必纯凶——竞技、征战、突破都需要"伤"的锐气。**凶中藏吉**。 |
| 杜门 | 闭塞、保密、技术、隐藏 | "杜"是堵住——不利公开沟通，**但利于保密、研究、隐藏**。中平门的深意：一种状态对此事不利、对彼事反利。 |
| 景门 | 表现、传播、文书、形象 | "景"是显现——利表达、传播，**但要警惕"表象强于实质"**。中平，因为"显示"本身是中性的，好坏看用途。 |
| 死门 | 终止、沉寂、固定、旧事 | "死"是结束——主停滞、收尾。**凶在"止"，但收尾整理之事反宜**。 |
| 惊门 | 惊疑、口舌、消息、变化 | "惊"是扰动——主突发与心理波动。**凶在"乱"，但不等于必然危险**。 |

**核心记忆法**：
> "休是缓和，生是增长，伤是碰撞，杜是关闭，景是呈现，死是终结，惊是扰动，开是开放。"

**深解**：这八种状态构成一个**完整的人生情境谱系**——从"开"到"死"，覆盖了行动的全周期：启动→生长→碰撞→关闭→呈现→终结→扰动→再开放。**八门不是八个孤立的标签，而是行动循环的八个阶段**。

### 八门原定宫位（本位）

| 门 | 宫位 | 方位 | 五行 |
| --- | --- | --- | --- |
| 开门 | 乾六宫 | 西北 | 金 |
| 休门 | 坎一宫 | 正北 | 水 |
| 生门 | 艮八宫 | 东北 | 土 |
| 伤门 | 震三宫 | 正东 | 木 |
| 杜门 | 巽四宫 | 东南 | 木 |
| 景门 | 离九宫 | 正南 | 火 |
| 死门 | 坤二宫 | 西南 | 土 |
| 惊门 | 兑七宫 | 正西 | 金 |

**深解·门与宫的五行对应并非偶然**：开门在乾金（金主刚健，宜开拓）；休门在坎水（水主静，宜休整）；生门在艮土（土生万物，宜生长）；伤门在震木（木主冲动，宜碰撞）；死门在坤土（坤主承载至极而止）。**每门落在与自身性质相合的宫位，是"同气相求"**——门与宫的五行相合则顺，相克则逆。

### 读门要点（不可单凭门论）

门落某宫后须综合判断：宫的五行与季节状态、同宫九星八神、天地盘天干组合、是否"门迫/空亡/入墓"、该宫与主体宫/目标宫的生克。

**深解**：这一条是奇门最核心的方法论——**没有任何符号可以单独定吉凶**。一扇"生门"落在克它的宫位、且遇凶神凶星，照样不利；一扇"死门"落在生它的宫位、且遇吉神，反而利于收尾之事。**这反映了一种"关系论"而非"实体论"的思维——吉凶不在符号本身，而在符号之间的关系**。

## 五、九星：天时气数的九种气质

### 吉凶属性

- **大吉星**：天辅、天心
- **多凶星**：天蓬、天芮
- 其余视组合而定

**深解**：九星不是天文意义的恒星，而是**九种"环境气质"的命名**。吉凶不是星本身的善恶，而是"这种气质在此情境中合不合宜"——天蓬主冒险，在征战中可能是胆识，在日常求财中可能是鲁莽。**星的吉凶随事而变**。

### 各星象意深解

| 星 | 象意 | 深解 |
| --- | --- | --- |
| 天蓬 | 冒险、欲望、机变 | 胆识与风险的化身——**利在破局，弊在失控**。 |
| 天芮 | 问题、学习、照料 | 缺陷与修复的化身——**不宜简单等同"疾病"**，它代表一切"需要被照料的状况"。 |
| 天冲 | 速度、行动、冲击 | 启动力的化身——**长于破局起步，弱在急躁难持久**。 |
| 天辅 | 文化、教育、协助 | 方法与支持的化身——**大吉，因为它给的是"可持续的辅助"**。 |
| 天禽 | 中正、统合、枢纽 | 中和的化身——**居中宫，象征统合一切力量的枢纽**。 |
| 天心 | 谋略、治理、技术 | 智慧与治理的化身——**大吉，因为它给的是"清晰的判断力"**。 |
| 天柱 | 言语、阻隔、支撑 | 结构的化身——**既可能是阻力，也可能是承重墙**。 |
| 天任 | 担当、稳定、积累 | 责任与积累的化身——**利在持久，弊在迟缓**。 |
| 天英 | 光彩、表现、热烈 | 光芒的化身——**利在显现，弊在虚浮**。 |

**深解·九星的哲学**：九星构成一个**完整的人格/环境谱**——有冒险（蓬）、有问题（芮）、有行动（冲）、有方法（辅）、有统合（禽）、有谋略（心）、有结构（柱）、有担当（任）、有光彩（英）。**这九种气质涵盖了一个组织或一个人"能做什么、会出什么问题"的全部面向**。古人用星名命名气质，是为了把抽象的"气数"变成可记忆、可辨识的符号。

## 六、八神：不可见力量的八种面目

按排布顺序：**值符、腾蛇、太阴、六合、白虎、玄武、九地、九天**。

| 神 | 象意 | 深解 |
| --- | --- | --- |
| 值符 | 众神之首，总领全局 | **最吉之神**——象征统帅、贵人、核心力量。它的深意是"当值的核心"——每个时辰都有一个主导力量，找到它就找到了全局的"眼"。 |
| 腾蛇 | 虚惊、怪异、缠绕、梦寐 | 主虚诈变异——**它不是真凶险，是"看起来可怕"**。提醒你不要被假象惊扰。 |
| 太阴 | 阴庇、隐藏、谋略、暗助 | 利密谋、荫蔽——**"暗助"是隐藏的支持力量，代表看不见的助力**。 |
| 六合 | 和合、合作、婚姻、媒介 | 利合作、谈判——**"和"是奇门里最被推崇的力量之一**，因为古人深知"和气生财、和则两利"。 |
| 白虎 | 凶煞、刑伤、血光、威武 | 主凶险、伤灾、官非——**最直白的凶神，代表可见的、剧烈的伤害**。 |
| 玄武 | 暗昧、盗失、口舌、欺骗 | 主失脱、暗昧、小人——**与白虎不同，玄武是"看不见的伤害"**——欺骗、暗算、不易察觉的损失。 |
| 九地 | 坚牢、潜伏、安静、积蓄 | 利藏匿、坚守、安葬——**"潜"的力量**，宜守不宜攻。 |
| 九天 | 刚健、扬威、远行、奋发 | 利出征、远行、公开之事——**"扬"的力量**，宜攻不宜守。 |

**深解·八神的分类逻辑**：八神可分为三组——

1. **核心与统帅**：值符（总领）
2. **吉神/助力**：太阴（暗助）、六合（和合）、九地（潜守）、九天（扬发）
3. **凶神/扰害**：腾蛇（虚惊）、白虎（明凶）、玄武（暗凶）

**这三种力量覆盖了"不可控因素"的全部面目**——主导力、助力、扰害。古人对"未知"的态度是：**不否认它的存在，而是给它命名、分类、排座次，让它在盘上"可被辨识"**——这本身是一种"以符号驯服未知"的认知努力。

### 流派差异说明

第五、六神在不同流派中称法不同：部分用白虎/玄武，部分用勾陈/朱雀，**但位置与排法完全相同**。

**深解**：这种"异名同位"说明符号的核心是**位置与功能**，不是名称——古人允许名称因流派而异，但符号在盘上的位置与作用不变。**这与现代系统论"接口稳定、实现可异"的思想暗合**。

### 排布规则

- 阳遁：八神顺排；阴遁：八神逆排。
- 值符随值符星（当值九星）落宫而定，其余七神按顺序依次排布。

**深解·顺逆的意义**：阳遁顺排，阴遁逆排——**阳顺阴逆是古人观察天道运行得出的规律**（冬至后阳气渐长、万物顺生；夏至后阴气渐长、万物逆收）。八神随阴阳遁而顺逆，意味着**"不可控因素"也随天道大势而变向**——连运气都要分顺逆。

## 七、三奇六仪与"遁甲"：地利与隐遁的智慧

### 三奇（吉祥之气）

| 天干 | 别名 | 深解 |
| --- | --- | --- |
| 乙奇 | 日奇 | 日之奇——光明正大的吉利 |
| 丙奇 | 月奇 | 月之奇——柔和明亮的吉利 |
| 丁奇 | 星奇 | 星之奇——微弱但持久的吉利 |

**深解**：三奇对应日、月、星——**天上三光**。古人认为天上的光明是最纯正的吉气，故以三奇命名三种吉利的能量。三奇落宫得地多主吉利，代表"光明正大的助力"。

### 六仪（六种能量状态）

戊、己、庚、辛、壬、癸。

**深解**：六仪是六个天干，代表六种不同的"能量状态"——古人不把它们叫"干"，而叫"仪"（仪仗、旗帜），意味着它们是**"甲"的仪仗队**，是保护"甲"的力量。

### "遁甲"的深层义理

甲为**元帅**（十干之首），隐遁于六仪之下，故名"遁甲"。

| 六甲 | 隐于 |
| --- | --- |
| 甲子 | 戊 |
| 甲戌 | 己 |
| 甲申 | 庚 |
| 甲午 | 辛 |
| 甲辰 | 壬 |
| 甲寅 | 癸 |

**深解·"遁甲"是全书的哲学核心**：

1. **甲是元帅，代表最核心的力量**——十干之首，最重要的东西。
2. **甲不直接出现，而是"隐遁"于六仪之下**——最重要的力量，反而要藏起来。

**这是全书的深层智慧：真正核心的东西，不暴露在前线，而是藏在仪仗之后**。这与兵法"避实击虚"、老子"大巧若拙"、王阳明"此心不动"是同一种哲学——**力量不在显而在隐，不在露而在藏**。

六甲分别隐于六仪之下，是一种**"分散隐遁"**——不是把所有力量藏在一处，而是分散藏于六处，增加保护层、降低被一锅端的风险。**这种"分散隐遁"的思维，与现代风险管理"不要把鸡蛋放一个篮子"完全同构**。

### 三奇六仪排布规则

- **阳遁**：顺布九宫（戊、己、庚、辛、壬、癸、丁、丙、乙 顺排）。
- **阴遁**：逆布九宫（逆排）。

**深解·顺序的深意**：排布顺序是"六仪在前，三奇在后"——**仪仗（保护层）在前，奇光（吉气）在后**。这与"遁甲"的哲学一致：先把保护层布好，再让吉气落在该落的位置。**先守后攻、先防后求**。

### 三奇格局

- **三奇得使（三奇到门）**：大吉格局——三奇的吉气正好落到对应的吉门上，**吉气与吉门相得，事半功倍**。
- **三奇入墓**：凶格——三奇的吉气被困在墓库之宫，**光明被埋，吉气无法发挥**。

**深解**：这两个格局说明——**奇吉不在符号本身，而在符号的"位置关系"**。三奇本是吉气，但落错地方（入墓）就变凶；落对地方（得使）就大吉。**吉凶永远是"关系"的产物，不是"实体"的属性**。

## 八、起局方法：从时间到盘面

### 阴遁与阳遁（以节气周期决定）

| 遁 | 适用 | 排布 |
| --- | --- | --- |
| 阳遁 | 冬至到夏至（阳气上升） | 九宫顺排 |
| 阴遁 | 夏至到冬至（阴气上升） | 九宫逆排 |

**深解·为什么以冬至夏至分界**：冬至是日照最短、阴极阳生之时；夏至是日照最长、阳极阴生之时。**以这两个"极转点"作为阴阳遁的分界，意味着奇门认为"决策的方向要随大势的转折而翻转"**——阳长时顺向布局，阴长时逆向布局。**顺应大势，不逆天而动**。

### 三元（上中下）

按日干支"符头"定三元。**符头**：甲日或己日。符头地支定三元：

| 符头地支 | 三元 |
| --- | --- |
| 子午卯酉 | 上元 |
| 寅申巳亥 | 中元 |
| 辰戌丑未 | 下元 |

**深解·三元的哲学**：上中下三元对应地支的"四正"（子午卯酉，正方）、"四生"（寅申巳亥，生方）、"四库"（辰戌丑未，墓库方）。**上元用正方（气最纯），中元用生方（气始生），下元用库方（气归藏）**——三元是从"纯"到"生"到"藏"的能量阶段。**这种以地支性质而非随机数字来分段的方式，体现了"阶段不同、气数不同"的认知**。

### 值符与值使（全局枢纽）

- **值符**：当时值班的九星，代表天时，反映全局主导力量。"值符随时干落宫"。
- **值使**：当时值班的八门，代表人事。"值使按时辰飞宫"。

**深解·"值班"的深意**：值符、值使都是"当值"的概念——**每个时辰都有一个星、一个门在"值班"**，它们是此时此刻的主导力量。**这种"值班"思维，把"时间"与"主导力量"绑定**——不同时辰有不同的主导，所以同一件事在不同时间做，结果不同。**这正是"择时"的理论根基**。

**断局先看值符、值使所在宫位**，二者是全局枢纽、占断最重要的参考点。

### 拆补法与置闰法（定局法对比）

| 维度 | 拆补法 | 置闰法 |
| --- | --- | --- |
| 换局 | 一到节气交节即刻换新节气的局 | 以符头为局起点，上中下三元各 15 日 |
| 三元 | 以符头及其地支判定，不置闰 | 每节气共 45 日 |
| 特点 | 明清以来通行，软件默认；三元与节气不完全对齐，靠"拆"与"补"处理节气首尾 | 因节气实际约 15.22 日，符头逐渐超前（"超神"），约每三年置一"闰局"（重复一个三元）校正（"接气"） |
| 一致性 | "正授"（符头与节气对齐）时两法一致；超神/接气偏差大时两法分歧 | 同左 |

**深解·两种定局法的哲学差异**：

- **拆补法**：交节即换——**"认节气不认符头"，以客观天文为准**。简单但牺牲了符号系统的内部一致性。
- **置闰法**：以符头为局起点，靠置闰校正——**"认符头不认节气"，以符号系统内部的一致性为准**，用闰局来校正与天文实际的偏差。

**两种方法反映两种认知取向**：拆补法是"天文优先"，置闰法是"系统优先"。**正授时两法一致，说明当系统与天文对齐时，两种取向殊途同归**——分歧只在系统漂移时才出现。

### 时家奇门转盘起局步骤（九步）

1. 定阴阳遁（按节气）
2. 定三元（按符头）
3. 查局数（查节气三元表）
4. 布地盘（戊己庚辛壬癸丁丙乙，阳顺/阴逆）
5. 定值符值使（按时辰旬首）
6. 转天盘（九星随值符整体旋转）
7. 飞值使布八门（八门随值使转动）
8. 排八神（阳顺阴逆）
9. 自动标注（旬空、驿马、门迫、击刑、三奇入墓）

**深解·九步的设计逻辑**：这九步不是任意顺序，而是一个**从宏观到微观、从框架到细节**的展开：

- 1-3 步定"时间维度"（阴阳遁→三元→局数）
- 4 步定"空间底层"（地盘）
- 5 步定"全局枢纽"（值符值使）
- 6-8 步定"四盘展开"（天盘→人盘→神盘）
- 9 步定"异常标注"（四害等）

**这个顺序体现了"先定大势，再填细节，最后查异常"的决策思路**——与现代项目管理的"先定方向、再填结构、最后查风险"完全同构。

### 转盘法与飞盘法

- **转盘法**：天干符号与九星随值符整体旋转，八门随值使整体旋转，**保持洛书九宫环上的刚性相对顺序**。
- **飞盘法**：天干、九星、八门逐宫飞布，**打乱相对顺序**。

**深解**：转盘法是"整体平移"——**保持内部结构不变，整体旋转**，思维是"系统整体不变，只换位置"。飞盘法是"逐宫飞布"——**打乱内部结构，每宫独立**，思维是"每个位置都独立计算"。**两种方法代表两种世界观：转盘法是"结构主义"，飞盘法是"原子主义"**。

## 九、吉格与凶格：格局即关系

### 主要吉格

青龙返首、飞鸟跌穴、玉女守门、三奇得使、五不遇时反吉。

### 主要凶格

腾蛇夭矫、朱雀投江、白虎猖狂、玄武入狱、太白入荧。

**深解·格局的本质**：吉格凶格不是某个符号的属性，而是**符号之间的特定组合关系**。吉格是天盘地盘、星门神干形成"相生相得"的组合；凶格是形成"相克相刑"的组合。**格局即关系——这是奇门最核心的认知：吉凶不在符号，在符号的组合方式**。

### 特殊格局

天遁、地遁、人遁、神遁等"遁格"。

**深解**：遁格是"某层力量遁藏"的特殊状态——**天遁是天时隐遁、地遁是地利隐遁**……它们代表"某层主导力量暂时退场"的特殊时刻。**遁不是消失，是"隐而待发"**——与"遁甲"的哲学一脉相承。

## 十、用神取用：不同事项的代表符号

| 事项 | 用神 | 深解 |
| --- | --- | --- |
| 自身 | 日干 | "我"是谁——以日干代表主体 |
| 财富 | 生门 | "生"主增长——求财看生机所在 |
| 事业/工作 | 开门 | "开"主通达——事业看能否打开局面 |
| 婚姻 | 乙奇（男）、庚（女） | 乙庚合——男女正配 |
| 文书/考运 | 景门 | "景"主显现——文书考运看能否"显示"出来 |

| 出行 | 开门、休门 | "开休"主通达与安和——出行要顺且安 |
| 疾病 | 天芮星、死门 | "芮"主问题、"死"主终止——疾病看问题与危机 |

**深解·用神的哲学**：不同事项取不同用神，说明**奇门不承认"一刀切"的吉凶**——同一盘局，问财看生门、问病看天芮，结论完全不同。**吉凶是"问什么"决定的，不是盘面决定的**——这把"问题意识"放在了第一位：**你问什么，盘就回答什么；你不问，盘无吉凶**。

### 读盘建议顺序

起局信息 → 局式 → 值符值使 → 用神落宫 → 宫间关系。

**深解**：这个顺序体现"从宏观到微观"——先看全局主导（值符值使），再看具体用神，最后查关系。**避免只抓一个符号下结论**，是防止"局部最优陷阱"——单看一个符号好就下结论，可能全局其实不利。

### 四害等特殊标记

排盘常以红色圆圈标记"四害"：**迫（门迫）、刑（击刑）、墓（入墓）、空（空亡）**。

| 概念 | 含义 | 深解 |
| --- | --- | --- |
| 旬空 | 时辰所在旬中空亡的地支 | "空"是力量不及——**该位置没有支撑**。 |
| 入墓 | 天干或星、门落入墓库之宫 | "墓"是力量被困——**有劲使不出**。 |
| 门迫 | 门临克宫，力量受制 | "迫"是行动受阻——**想做但被环境压住**。 |
| 击刑 | 天干落于相刑之宫 | "刑"是内部冲突——**自己的力量互相打架**。 |
| 驿马 | 主奔波、变动的神煞 | "马"是变动——**不是凶，是要动**。 |

**深解·四害的共同点**：迫、刑、墓、空都指向"力量被削弱或困住"——**它们不是"凶"，是"使不上劲"**。奇门把这种"使不上劲"的状态细分为四种：被环境压（迫）、内部冲突（刑）、被困住（墓）、没有支撑（空）。**这种细分本身就是一种精细的力量诊断学**。

## 十二、哲学总结：奇门遁甲的世界观

读完奇门遁甲，可以提炼出几条贯穿全书的世界观：

1. **时空一体**：时间（时辰）与空间（九宫）不是分离的，而是同一盘面的两面——**时间变则盘变，盘变则方位的意义变**。这与现代物理"时空"概念暗合。

2. **关系论而非实体论**：没有任何符号单独定吉凶，吉凶永远是符号之间的关系。**这是一种"关系思维"——意义在连接中产生，不在孤立中存在**。

3. **力量分层**：天地人神四层，是古人对"决策变量"的完整分类——**宏观（天）、中观（地）、微观（人）、未知（神）**。四层不可偏废。

4. **核心隐遁**："遁甲"是全书哲学核心——**最重要的力量不暴露，要藏**。这与"厚而无形""大智若愚""此心不动"是同一种智慧。

5. **顺势而为**：阳遁顺排、阴遁逆排，八神随阴阳遁顺逆——**顺应大势，不逆天而动**。择时择方的本质，是"找大势顺的方向"。

6. **问什么答什么**：用神随事项而变——**吉凶不是盘面决定的，是"问题"决定的**。这把"问题意识"放在了第一位。

7. **由繁入简**：4320→18，是认知从"案例库"到"模式库"的跃迁——**真正的掌握不是记住所有案例，而是提炼出少量模式**。

8. **以符号驯服未知**：八神给"不可控因素"命名、分类、排座次——**古人对未知的态度不是恐惧，而是"命名它、辨识它、与它共处"**。

## 十三、金句精解

1. **"奇门遁甲是三式之首，古称帝王之学。"**——"首"不在"最准"，在"维度最全"——天地人神四层同时入局，故称帝王之学。

2. **"以时间起局，把天、地、人、神四个层面的信息编织进洛书九宫。"**——这是奇门总纲：**以客观时间为锚，把四维变量编入空间盘面**。

3. **"天盘九星象天时，地盘三奇六仪象地利，人盘八门象人事，神盘八神象无形之助力。"**——四盘即四维：**宏观环境、中观资源、微观行动、不可控因素**。

4. **"冬至后阳遁、夏至后阴遁。"**——以极转点分阴阳：**大势转折处，方向要翻转**。

5. **"甲为元帅，隐遁于六仪之下，故名遁甲。"**——全书哲学核心：**最重要的力量不暴露，要藏**。

6. **"断局先看值符、值使所在宫位，二者是全局枢纽。"**——先找主导力量：**每个时辰都有"值班"的主导，找到它就找到了全局的眼**。

7. **"避免只抓一个符号下结论。"**——关系论方法论：**吉凶在符号之间的关系，不在符号本身**。

8. **"休是缓和，生是增长，伤是碰撞，杜是关闭，景是呈现，死是终结，惊是扰动，开是开放。"**——八门即行动八阶段：**从启动到终结的完整循环**。

## 十四、问答要点（常见问题速答）

- **Q：奇门遁甲是什么？为什么叫"帝王之学"？**
  是中国传统术数"三式"之首，一套以时间、九宫、干支组织信息、把天地人神四层信息编入洛书九宫的决策模型。古时多用于军事与国政，故称"帝王之学"——"首"在维度最全，不在"最准"。

- **Q：数理奇门与法术奇门的区别？**
  数理奇门侧重用符号与盘面推演吉凶（预测）；法术奇门涉及咒语秘诀，常被视为迷信。**值得研究的是数理奇门——它是一套成熟的符号推演体系**。

- **Q：四盘分别是什么、象征什么？**
  天盘九星（天时/宏观环境）、地盘三奇六仪（地利/中观资源）、人盘八门（人事/微观行动）、神盘八神（无形助力/不确定性）。

- **Q：什么是"遁甲"？为什么"甲"要隐遁？**
  甲为十干之首（元帅），隐遁于六仪之下。"遁甲"的哲学是：**最重要的力量不暴露，要藏**——与兵法"避实击虚"、老子"大巧若拙"同构。

- **Q：阳遁阴遁怎么定？**
  冬至到夏至用阳遁（顺排），夏至到冬至用阴遁（逆排）。**以极转点分界，意味着大势转折处方向要翻转**。

- **Q：拆补法与置闰法有何不同？**
  拆补法交节即换局（天文优先），置闰法以符头为局起点、靠置闰校正（系统优先）。**两法在正授时一致，分歧只在系统漂移时**。

- **Q：断局先看什么？**
  先看值符、值使所在宫位（全局枢纽），再查用神落宫及其与日干宫、目标宫的生克。**避免只抓一个符号下结论——吉凶在关系，不在符号**。

- **Q：八门哪三吉门？为什么这三门吉？**
  开门、休门、生门。吉在"行动与时机契合"——开主通达、休主存势、生主增长。**吉凶不是门本身的善恶，是"行动与时机契合度"**。

- **Q：什么是"四害"？它们是凶吗？**
  迫（门迫）、刑（击刑）、墓（入墓）、空（空亡）。**它们不是"凶"，是"使不上劲"**——被环境压住、内部冲突、被困住、没有支撑。

- **Q：奇门遁甲是迷信吗？**
  属于传统文化范畴的术数模型，融汇天文历法、阴阳五行、八卦九宫、干支，体现古人"天时地利人和"的系统思维。**它的价值不在"准不准"，而在它是一套成熟的符号推演体系，反映了中国古人独特的"关系论"思维**。其象意解释仅供文化研究、学术了解与娱乐参考，不应作为投资、医疗、法律等重大决定的依据。
